AuDe - Progiciel de consultation du Décret n°01494/PR/MTEPS

Cette version respecte la structure du classeur Excel d’origine : ACCUEIL, CONSULTATION, INDEX, ARTICLES, SOMMAIRE et GUIDE.

Fonctionnalités conservées uniquement :
- référentiel complet des 263 articles ;
- recherche par article, exigence, thème ou risque ;
- consultation détaillée de chaque article ;
- sauvegarde et restauration par fichier JSON ;
- conservation locale des données dans le navigateur.

Lancement : décompresser puis ouvrir index.html dans Microsoft Edge ou Google Chrome.
